# notebooks/

Exploratory data analysis and one-off experimentation. Name notebooks with a domain prefix and short description, e.g. `transit_01_eda_ridership.ipynb`, `energy_01_load_seasonality.ipynb`, `weather_01_anomaly_scan.ipynb`, so ownership is obvious at a glance.

Notebooks are for exploration, not production logic — once an approach works, move the code into `features/<domain>/` or `models/<domain>/`.
